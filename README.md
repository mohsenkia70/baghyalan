# عمارت یلان — نمونه اولیه PWA

نمونه اولیه کامل و قابل‌اجرا از پلتفرم دیجیتال لوکس عمارت یلان، ساخته‌شده با Next.js 16.3.3 (App Router)، TypeScript، Tailwind CSS v4 و Framer Motion.

## اجرای پروژه

```bash
npm install
npm run dev
```

سپس مرورگر را روی آدرس زیر باز کنید:

```
http://localhost:3000
```

## بخش‌های اصلی

- **تجربه مشتری** (موبایل‌محور، فارسی، راست‌چین): از مسیر `/` شروع می‌شود (صفحه شروع سینمایی) و شامل معرفی عمارت، گالری، برنامه‌ریزی مراسم، پکیج‌ها، رزرو بازدید، داشبورد «مراسم من» و چت با مشاور است.
- **پنل مدیریت مجموعه**: در مسیر `/admin` قابل دسترسی است و شامل داشبورد KPI، CRM لیدها (نمای کانبان و لیست)، تقویم مدیریت، مدیریت مراسم‌ها، پنل روز مراسم، بازدیدها، مدیریت محتوا، گزارش‌ها و مرکز اعلان‌ها می‌شود.

## نکات فنی

- **احراز هویت — فاز اول بک‌اند واقعی**: ورود از طریق `POST /api/auth/login` انجام می‌شود؛ رمزهای عبور با `scrypt` هش و در دیتابیس SQLite واقعی (`node:sqlite`، فایل `data/app.db`) ذخیره می‌شوند. نشست کاربر با کوکی امن HttpOnly و توکن امضاشده (HMAC) نگهداری می‌شود. فایل `proxy.ts` (جایگزین `middleware.js` در Next 16) پیش از رندر هر صفحه، دسترسی مسیرهای مشتری و `/admin` را سمت سرور بررسی و در صورت نبود نشست معتبر، ریدایرکت می‌کند.
  - دیتابیس در اولین اجرا به‌صورت خودکار ساخته و با دو کاربر تستی seed می‌شود (نیازی به دستور جداگانه نیست).
  - **کاربر تستی مدیریت**: `09120000000` / `admin123`
  - **کاربر تستی عروس و داماد**: `09121234567` / `123456`
  - فاز بعدی: وصل‌کردن CRM، رزروها و پرداخت‌ها به همین دیتابیس، و در نهایت مهاجرت به Postgres روی هاست واقعی.
- سایر داده‌های نمایشی (گالری، پکیج‌ها، CRM، مراسم‌ها) همچنان Mock هستند و در `lib/mock-data/` نگهداری می‌شوند.
- ۵ تصویر واقعی عمارت یلان در `public/images/venue/` قرار دارند و در سراسر پروژه استفاده شده‌اند.
- PWA: شامل `manifest.json`، Service Worker پایه (`public/sw.js`) و کامپوننت نصب/آفلاین (`components/system/PwaManager.tsx`) است.
- برای build تولیدی: `npm run build && npm start`
